# Local build — not for external distribution

This disk image contains an ad-hoc signed, arm64-only development build for use on the
owner's Mac. It is not signed with Developer ID and has not been notarized by Apple.

Do not present this artifact as a public release. The final release gate requires an active
Apple Developer Program membership, a Developer ID Application certificate, successful
Apple notarization and Gatekeeper verification on a clean Apple Silicon Mac.
