# Stock Monitor macOS 隐私说明

更新时间：2026-09-07

Stock Monitor macOS 客户端连接用户自行管理的 Stock Monitor 服务端。客户端不直接连接
数据库、Redis、行情供应商或 Interactive Brokers，也不保存这些服务的密钥。

客户端仅在系统 Keychain 中保存用于恢复登录的刷新令牌；访问令牌只存在于进程内存中。
退出登录会清除本地认证信息。客户端不把 AI 对话正文、IBKR 数据或投资内容写入磁盘缓存，
也不包含广告追踪或第三方分析 SDK。随应用提供的 Privacy Manifest 声明客户端不进行追踪，
且不由客户端收集数据用于广告、营销或第三方分析。

用户主动选择“导出支持诊断”时，客户端仅生成版本号、构建号、macOS 版本、CPU 架构、
兼容性状态及匿名运行计数。诊断不包含令牌、用户名、账户标识、持仓、交易、AI 对话、
IBKR 标识、请求 URL 或请求/响应正文；文件只保存到用户在系统面板中选择的位置。

账户、投资组合、行情、研究内容及 AI 数据的处理由用户所连接的自托管服务端负责。
客户端本身不会建立独立云端账户或保留上述业务数据。数据保留与删除由用户自托管服务端的
管理员负责；支持请求也由该部署的管理员处理。未来若加入由应用开发者运营的支持服务或
遥测，将在启用前更新本说明并重新审查 Privacy Manifest。
