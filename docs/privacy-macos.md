# Stock Monitor macOS 隐私说明

更新时间：2026-09-05

Stock Monitor macOS 客户端连接用户自行管理的 Stock Monitor 服务端。客户端不直接连接
数据库、Redis、行情供应商或 Interactive Brokers，也不保存这些服务的密钥。

客户端仅在系统 Keychain 中保存用于恢复登录的刷新令牌；访问令牌只存在于进程内存中。
退出登录会清除本地认证信息。Goal M1 不写入 AI 对话正文、IBKR 数据或投资内容缓存，
也不包含广告追踪或第三方分析 SDK。

账户、投资组合、行情、研究内容及 AI 数据的处理由用户所连接的自托管服务端负责。
正式分发前，本说明将补充支持联系方式、数据保留周期与删除请求流程。
